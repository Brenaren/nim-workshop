# NIM Workshop
> **What is the purpose of the workshop?**
  The NIM workshop aims to introduce Generative AI, RAG and state-of-the-art enterprise tools for running these workloads.
  The workshop includes a hands-on programming section with Python to give participants first-hand experience with GenAI tools. This does not require prior Python experience.
> 
> **What is covered in the workshop?** 
> NVIDIA NIM (Nemo Inference Microservice) for LLMs
  RAG (Retrieval Augmented Generation) - what and why?
  NVAIE (NVIDIA AI Enterprise) and Nemo Microservices (including NIM, Nemo Retriever for Embedding and Reranking, Nemo Guardrails)
  LLM Inference optimization with TensorRT-LLM and Triton Inference Server
  Hands-on workshop with NIM, model fine-tuning with LoRA, and performance evaluation
> 
> **Who is the workshop for?**
  Anyone who’s interested in working with Generative AI. A light background with Python and Docker would help, but it’s not required.
  The hands-on portion will involve running pre-written Python notebooks (not required to write code yourself) and talking through the functionality.
